GUI

Tkinter

Same backend as the terminal UI with a windowed frontend. No extra deps, since tkinter ships with Python.

sudo .venv/bin/python3 src/hackmate_gui.py      # linux / macos
.venv\Scripts\python.exe src\hackmate_gui.py    # windows, run powershell as administrator

Flutter

A newer windowed frontend talking to the same Python backend over a JSON-RPC bridge (src/bridge.py). Build history, log checker, EFI health check, disk map, restore, USB mapping, config editor and the full guided/manual build wizard all work. It isn't distributed as a prebuilt exe yet, so you build it yourself.

You need the Flutter SDK plus platform build tools: Visual Studio Build Tools with the "Desktop development with C++" workload on Windows, Xcode on macOS, gtk3/clang/cmake/ninja on Linux.

cd hackmate/gui-flutter
flutter pub get
flutter run
flutter build windows
flutter build macos
flutter build linux

Windows: run the built exe. It prompts for admin (UAC) and the Python backend inherits that.

Linux / macOS: the app doesn't self-elevate, so launch it with sudo from a terminal.

Linux and macOS support was just added and has only been built and tested on Windows so far. If something's broken there, open an issue.
