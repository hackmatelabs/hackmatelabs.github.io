Linux and macOS

git clone https://github.com/hackmatelabs/hackmate.git
cd hackmate
python3 setup.py
sudo .venv/bin/python3 src/hackmate.py

Always use the full path to the venv python (.venv/bin/python3) with sudo, not python3 or uv run. sudo doesn't inherit your PATH, so it won't find uv or your user-installed packages. If you got sudo: uv: command not found, this is why.

macOS: lspci not found

macOS is fully supported now. Pull the latest and rerun.
