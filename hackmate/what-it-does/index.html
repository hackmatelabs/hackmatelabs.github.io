What It Does

  1. Scans your hardware: CPU, GPU, audio, ethernet, Wi-Fi, touchpad, NVMe, Thunderbolt.
  2. Shows which macOS versions are compatible with your exact hardware.
  3. You pick a USB drive. Internal disks are hidden so you can't wipe the wrong one.
  4. Everything after that is automated:
    • Formats the USB as FAT32 and creates the EFI structure
    • Downloads macOS recovery straight from Apple
    • Generates SMBIOS (serial, MLB, UUID, ROM)
    • Generates a config.plist with the correct quirks for your hardware
    • Downloads kexts from GitHub releases
    • Downloads the latest OpenCore release
    • Generates SSDTs from your actual DSDT using SSDTTime

Kext sources are checked before the USB is formatted, so a dead download source shows up as a warning instead of a kext silently going missing.

Graphical boot picker

New EFI builds boot into the hackmate-core graphical picker instead of OpenCore's text menu. The build screen's classic-picker option turns it off.
