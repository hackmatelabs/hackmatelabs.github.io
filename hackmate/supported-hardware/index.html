Supported Hardware

CPU generations

  • Sandy Bridge, Ivy Bridge, Haswell, Broadwell
  • Skylake, Kaby Lake, Coffee Lake
  • Comet Lake / Ice Lake
  • Rocket Lake and newer desktops, with a supported AMD dGPU
  • AMD Ryzen / Threadripper desktops

Intel 2nd to 10th gen is the normal range. 11th gen and newer Intel Xe graphics have no macOS driver, so those desktops need a supported AMD dGPU and those laptops usually aren't viable. hackmate flags dead ends before it builds.

Laptops tested

ThinkPad T480s, T480, T470, X1 Carbon · Dell XPS 13/15 · HP EliteBook · ASUS Zenbook · Acer Aspire

Platforms

Laptops, desktops, mini-PCs.

macOS versions

Ventura, Sonoma, Sequoia, Tahoe (macOS 16).

Reference build

Built and tested on a ThinkPad T480s (i5-8350U, Intel 8265 Wi-Fi, Kaby Lake-R).
