hackmate-hwdb

A repo that improves hackmate using real users' hardware logs.

hackmate's compatibility checks (which macOS versions work on which CPU gen, which kexts get picked, and so on) are based on general known-good rules. This repo collects confirmed reports from actual machines so the tool gets more accurate over time, and so you can check whether your exact device has already been tested before trying it.
