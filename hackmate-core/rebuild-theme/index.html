Rebuild the Theme

tools/build_theme.py regenerates Resources/. It composites the banner over a wallpaper (blurred, darkened), redraws Apple.icns, tints the selection chrome, and pulls Font/ and Label/ from OcBinaryData.

python tools/build_theme.py \
  --wallpaper /path/to/wallpaper.jpg \
  --ocbinary  /path/to/OcBinaryData \
  --goldengate /path/to/OcBinaryData/Resources/Image/Acidanthera/GoldenGate

--blur, --brightness and --dark tune the backdrop. Edit BANNER, SUBTITLE and LEGEND at the top of the script for different text.

tools/preview.py renders a mockup PNG without booting anything. tools/build_test_efi.py plus tools/qemu_shot.py build a throwaway ESP and boot it in QEMU + OVMF.
