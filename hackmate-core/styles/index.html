Styles and Resolution

Styles

  • full (PickerAttributes 145): banner, legend, shutdown/restart buttons
  • minimal (209): same, no shutdown/restart buttons

Resolution

Background.icns is centred, not stretched. Three variants ship: Background.icns (1080p), Background_1440p.icns and Background_2160p.icns. The install command with --resolution swaps in the right one. Otherwise rename the file yourself, or regenerate the theme. A mismatch just letterboxes against DefaultBackgroundColor (black).

For a 4K panel also set NVRAM UIScale to 02.

Notes

  • OpenCanopy's layout (icon size, row position, spacing) is fixed. A theme controls colours, images and labels only. The banner and legend live inside Background.icns, positioned to sit clear of the entry row.
  • The auto-detected macOS entry currently shows the generic drive icon instead of the Apple logo. It's a flavour-resolution quirk and purely cosmetic.
