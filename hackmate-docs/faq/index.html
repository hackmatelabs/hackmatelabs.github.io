FAQ

Do I need a Mac to use hackmate?

No. It runs on Linux, Windows and macOS, so any computer you have lying around can make the USB.

Will this work on my machine?

See Supported Hardware. Run hackmate and it flags dead ends before it builds.

Is this the same as following the Dortania guide by hand?

hackmate uses the same tools Dortania recommends (macrecovery, SSDTTime, OpenCore) and automates every step. The output EFI is equivalent to what you'd build by hand.

Can I hackintosh a ThinkPad?

Yes. hackmate was built and tested on a ThinkPad T480s. Intel Wi-Fi (itlwm + HeliPort) and the trackpad (VoodooI2C) are supported.

Does it work on Windows without Python?

Yes, grab HackMate.exe from the releases page.

Does hackmate download the full macOS installer?

Not currently. It downloads Apple's recovery image (about 600 MB), which then downloads the full macOS payload from Apple after you boot it. If recovery shows PKDownloadError 8 or your network blocks Apple's installer servers, try a different connection or prepare a full installer on a Mac. hackmate can't bypass filtering inside recovery.

Does Intel Wi-Fi show up as native Wi-Fi on Tahoe?

Not with the onboard Intel chip. AirportItlwm hasn't had a build past Sonoma since mid-2024, so Sequoia and Tahoe use itlwm + HeliPort. That gives internet access but no menu bar icon and no AirDrop/Handoff over Wi-Fi. For native Wi-Fi, swap in an Apple-supported Broadcom card (BCM94360CD, DW1560, etc). hackmate warns you and offers that path when it detects Intel-only Wi-Fi.

My antivirus flags hackmate.exe

Known false positive with PyInstaller exes. See Windows.
