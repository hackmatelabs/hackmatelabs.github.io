After Install

  • Run USBToolBox (saved to EFI/HackMate-Extras/) inside macOS to map your USB ports.
  • Swap the placeholder USBMap.kext for the one you generate, or use hackmate's USB mapping screen.
  • Run the EFI health check any time to see what's wrong with your EFI.
