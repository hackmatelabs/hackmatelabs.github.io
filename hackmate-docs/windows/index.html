Windows

Exe (easiest)

Download HackMate.exe from the latest release and run it as administrator. No Python, venv or setup needed.

Some antivirus engines (Bkav, GridinSoft, Zillya) flag the exe. This is a known false positive with PyInstaller-built executables. Defender, Kaspersky, ESET, CrowdStrike and Sophos report it clean, and the exe is built from source on GitHub Actions if you want to check the build logs.

From source

Has to be run as administrator. Right-click PowerShell and choose Run as administrator first.

git clone https://github.com/hackmatelabs/hackmate.git
cd hackmate
python setup.py
.venv\Scripts\python.exe src\hackmate.py

Always use .venv\Scripts\python.exe, not python or uv run, so all the deps are there.

USB formatting fails

Fixed in the latest update. If it still fails, format the USB as FAT32 (GPT) in Disk Management yourself, then use the already formatted option in hackmate.
